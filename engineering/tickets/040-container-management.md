# 040 — 容器管理員可以建立、檢視、操作容器並查看日誌、終端機與暴露範圍

**Epic:** 容器引擎（`epic:containers`）  
**User Story:** 管理員可以管理容器引擎  
**Milestone:** M2 容器、Compose 與 GitHub  
**Blocked by:** 039 管理員可以看到 Docker、Podman、K3s 各自狀態並在頁面一鍵安裝 Docker, 027 使用者可以在網頁使用授權終端機，且稽核政策可設定  
**規格章節:** 14｜Docker、Podman、映像與登錄站  
**Issue:** [#40](https://github.com/HazelnutParadise/hazelminx/issues/40)  

## What it delivers

容器 CRUD 與生命週期、完整設定與資源限制、即時與歷史日誌（分頁、續接、截斷提示）、容器終端機與檔案、暴露範圍（容器 Port、主機映射、綁定 IP、協定、代理入口）、容器設定政策檢查（特權、host network、裝置、敏感 bind mount 需對應主機權限）。

## Acceptance criteria

- [ ] **CTR-001** 容器管理員可以建立、檢視、啟停、暫停、重啟、改名與刪除容器。 — 完成條件：顯示引擎與節點；刪除預設不刪持久資料；不修改叢集控制的底層容器。
- [ ] **CTR-002** 管理員可以查看完整容器設定及資源限制。 — 完成條件：CPU、RAM、重啟策略、健康檢查、使用者、裝置與掛載可核對實際值。
- [ ] **CTR-003** 使用者可以看即時與歷史日誌、搜尋並匯出授權片段。 — 完成條件：支援分頁、續接、時間戳與截斷提示，日誌量大不拖垮管理服務。
- [ ] **CTR-004** 授權者可以進入容器終端機、上下載檔案與檢視程序。 — 完成條件：明確顯示容器使用者；操作受稽核，沒有 shell 的映像不被標為故障。
- [ ] **CTR-012** 管理員可以看到容器對外暴露的實際範圍。 — 完成條件：區分容器內 Port、主機映射、綁定 IP、協定及代理入口；0.0.0.0 明示可能公開。
- [ ] 刪除預設不刪持久資料
- [ ] 0.0.0.0 明示可能公開
- [ ] 容器管理員掛載宿主機根目錄時要求主機高風險權限，不能利用 Docker 逃過角色限制
- [ ] **ENV-003** 容器、映像、網路、儲存卷以環境為範圍：範圍列可選全部、節點或單一環境，表格有「環境」欄。
- [ ] **ENV-004** kind、k3d、minikube 的節點容器與 K8s 管理的容器標「由 <叢集> 管理」，寫入動作停用並導向 Kubernetes 頁，統計不重複計數。
- [ ] **ENV-007** Compose 專案、應用安裝、計畫任務綁定環境；節點上同種引擎多個時要求選擇，不自動猜。
- [ ] （增補 03 ROB-009，擁有票 020）容器被 OOM 終止時，事件寫出 OOMKilled 與記憶體限制並連到該容器；容器頁顯示 PID 數與檔案描述元開啟數。
