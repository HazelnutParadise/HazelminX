# 047 — 使用者可以用 GitHub 網頁授權或 PAT 建立可重用連線，並保存多帳號多授權

**Epic:** GitHub 來源（`epic:github`）  
**User Story:** 使用者可以從 GitHub 部署  
**Milestone:** M2 容器、Compose 與 GitHub  
**Blocked by:** 009 擁有者可以登入、建立帳號與角色，未授權的 API 呼叫一律被拒絕, 011 管理員可以安全保存機密，且主金鑰可輪替並驗證舊備份仍可解密, 010 整合者可以用 /management/v1 的分頁、版本條件與工作回應操作資源  
**規格章節:** 15｜完整 Compose、GitHub 與環境變數  
**Issue:** [#47](https://github.com/HazelnutParadise/hazelminx/issues/47)  

## What it delivers

GitHub App 自架精靈（manifest）與手動設定、授權請求（state、工作階段、回呼白名單、PKCE）、回呼核對帳號／安裝／Repo 關係、PAT 連線驗證、多帳號多授權模型、短效 Token 更新、內網環境的回呼與 Webhook 可達性分開檢查。

## Acceptance criteria

- [ ] **GIT-001** 使用者可以透過 GitHub 網頁授權連接帳號。 — 完成條件：不在 HazelminX 輸入 GitHub 密碼；回到平台後顯示實際帳號與授權範圍，不新增平台管理員。
- [ ] **GIT-002** 使用者可以輸入一次 PAT，建立可重用連線。 — 完成條件：向 GitHub 驗證身分與基本可用能力；秘密不回顯；之後建立多個專案不再要求重貼。
- [ ] **GIT-003** 使用者可以同時保存多個 GitHub 帳號。 — 完成條件：可命名、切換、停用與重新授權；穩定帳號 ID 區別身分，改名與切換不污染另一帳號。
- [ ] **GIT-004** 使用者可以為同一帳號保存多份不同範圍授權。 — 完成條件：不同個人／組織 PAT 或 App 安裝可並存；任一輪替不覆寫其他授權。
- [ ] **GIT-013** 管理員可以在自己的 HazelminX 建立或接入自己的 GitHub App。 — 完成條件：支援引導設定與手動輸入 App 設定；秘密留在自架管理端，不依賴產品作者雲端。
- [ ] **GIT-014** 管理員可以按能力給予最小 GitHub 權限。 — 完成條件：基本讀取不強求 Webhook 管理、內容寫入或組織管理；拒絕額外權限不使唯讀部署入口失效。
- [ ] **GIT-015** 使用者可以安全完成或取消授權回呼。 — 完成條件：驗證一次性 state、工作階段、有效期、回呼與帳號；重播、錯安裝與跨使用者綁定遭拒。
- [ ] **GIT-016** 系統可以安全取得及更新短效 App Token。 — 完成條件：依實際效期與最小 Repo 範圍使用；不硬寫 Token 長度；PAT 到期走重新授權而非假更新。
- [ ] **GIT-031** 使用者可以在純內網環境使用合適的部署入口。 — 完成條件：分開檢查瀏覽器回呼與 GitHub Webhook 可達性；提供 PAT／定期檢查，不自動公開管理頁。
- [ ] 連接 GitHub 不新增平台管理員，也不是平台登入
- [ ] 重播 state、換工作階段、偽造 installation ID 或外部 redirect 均被拒

## Acceptance tests（第 42 章）

- **GH-T01** 登入 GitHub 後授權一個帳號，再返回已登入的 HazelminX。 → 顯示真實帳號與授權範圍，不建立新平台管理員；取消流程不變更原連線。
- **GH-T02** 貼入有效 PAT，建立兩個 Repo 部署專案。 → 只需保存一次，兩專案綁同一連線但設定與資料分開；回應與日誌不含明文。
- **GH-T03** 同時連接兩個帳號，名稱相似且各有私人 Repo。 → 切換清單不混用身分或秘密；帳號改名仍是原 ID。
- **GH-T04** 同一帳號建立個人與兩個組織的不同範圍 PAT。 → 三份授權並存，組織批准狀態分開；輪替一份不覆寫其他份。
- **GH-T12** 在自架環境建立 App，再檢查前端、節點與出站流量。 → App 可由使用者自行持有；私鑰不下發，不依賴 HazelminX 作者雲端。
- **GH-T13** 僅授 Repo 內容讀取，拒絕內容寫入與 Webhook 管理權。 → 可選 Repo 與手動部署，顯示可用 polling；不強求管理組織。
- **GH-T14** 重播 code／state、換工作階段、偽造 installation ID 或外部 redirect；另測合法重新授權失敗與取消。 → 惡意回呼遭拒；合法流程取消或失敗保留 Compose、節點與 .env 參照，不接錯帳號、不新增連線、不寫秘密到網址或持久瀏覽器儲存。
- **GH-T15** 短效 App Token 到期與格式長度變動，並另測 PAT 到期。 → 按實際效期更新 App 憑證；不依字串格式誤拒；PAT 要重新授權。
