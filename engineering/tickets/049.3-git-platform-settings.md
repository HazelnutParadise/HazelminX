# 049.3 — 使用者可以為 Git 來源的單元套用平台 .env 與客製設定，新 commit 不覆寫

**Epic:** GitHub 來源（`epic:github`）  
**User Story:** 使用者可以從 GitHub 部署  
**Milestone:** M2 容器、Compose 與 GitHub  
**Parent:** 049  
**Blocked by:** 049.1, 045  
**規格章節:** 15｜完整 Compose、GitHub 與環境變數  
**Issue:** [#187](https://github.com/HazelnutParadise/hazelminx/issues/187)

## What it delivers

Git 來源單元的每個環境各自有平台 `.env` 與覆寫層（票 045 的分層）；換到新 commit 時保留既有的掛載、網路與 Port 設定；GitHub 的秘密不當成應用變數。

## Acceptance criteria

- [ ] **GIT-010** 使用者可以為挑選的 Repo 套用平台 `.env` 與客製設定。 — 完成條件：多環境設定分開；GitHub 秘密不當作應用變數；新 commit 不覆寫既有掛載、網路與 Port。

## Acceptance tests（第 42 章）

- **GH-T10** 由 Repo 選擇器部署後修改平台 `.env`、Network、Port 與 Volume，再收到 push。 → 設定不被覆寫，正式／測試資料分開，GitHub 秘密未注入應用。
