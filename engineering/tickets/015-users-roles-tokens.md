# 015 — 擁有者可以管理使用者、角色、資源範圍與有期限的 API Token

**Epic:** 身分與存取（`epic:iam`）  
**User Story:** 擁有者可以控制誰能做什麼  
**Milestone:** M1 單機主機管理  
**Blocked by:** 009 擁有者可以登入、建立帳號與角色，未授權的 API 呼叫一律被拒絕, 010 整合者可以用 /management/v1 的分頁、版本條件與工作回應操作資源  
**規格章節:** 05｜誰能用、誰能做什麼  
**Issue:** [#15](https://github.com/HazelnutParadise/hazelminx/issues/15)  

## What it delivers

使用者與角色管理畫面、資源範圍指派、API Token 建立（只顯示一次）、停權同時撤銷工作階段與 Token、選配外部身分登入並保留本機救援帳號。

## Acceptance criteria

- [ ] **IAM-004** 管理員可以建立有期限、範圍及用途的 API Token。 — 完成條件：Token 只在建立時完整顯示；撤銷及到期後拒絕新操作。
- [ ] **IAM-009** 使用者停權時，平台同時撤銷其管理工作階段與平台 Token。 — 完成條件：既有執行中任務依安全取消政策處理；不任意中止不可中斷的磁碟寫入。
- [ ] **IAM-010** 管理員可以選配外部身分登入，仍保留本機救援帳號。 — 完成條件：外部登入服務故障時，不會永久失去管理能力；角色對應有預覽。
- [ ] 停權時執行中任務依安全取消政策處理，不中止不可中斷的磁碟寫入
- [ ] 外部登入故障時不會永久失去管理能力
- [ ] （設計審查 2026-11-08）送出邀請後顯示結果（連結效期、寄送狀態），身分與存取頁有「待接受邀請」清單，可以重送與撤回。
- [ ] （後續事項 2026-11-11）使用者可以自己改密碼（需要目前的密碼），改完後其他工作階段失效。規格第 05 章與各票原本都沒有這一項，密碼外洩時已登入的使用者無法自救。
- [ ] （後續事項 2026-11-11）帳號有自己的時區偏好，使用者看到的時間依它顯示；沒設定時依瀏覽器時區（`web/src/lib/time.ts` 的 `browserTimeZone`）。票 018 的 SET-001 是平台時區，不是這一項。
