# 028 — 使用者可以瀏覽、整理、授權與追蹤宿主機檔案

**Epic:** 檔案管理（`epic:files`）  
**User Story:** 使用者可以管理主機檔案  
**Milestone:** M1 單機主機管理  
**Blocked by:** 012 維運者可以執行需要高權限的固定動作，而 Agent 主程序維持低權限, 017 使用者可以在主導覽、全域搜尋與工作中心之間完成日常操作  
**規格章節:** 12｜宿主機檔案與跨節點傳輸  
**Issue:** [#28](https://github.com/HazelnutParadise/hazelminx/issues/28)  

## What it delivers

檔案瀏覽（擁有者、權限、連結目標、所在磁碟、分頁）、新增／複製／搬移／改名／刪除、權限與 ACL、搜尋上限、回收桶、分享連結、從掛載或備份頁開啟實際路徑、文字檔歷史與回復。

## Acceptance criteria

- [ ] **FIL-001** 使用者可以瀏覽授權目錄、隱藏檔與檔案資訊。 — 完成條件：顯示擁有者、群組、權限、大小、時間、連結目標與所在磁碟；大目錄分頁。
- [ ] **FIL-002** 使用者可以新增、複製、搬移、重新命名與刪除檔案。 — 完成條件：目標已存在時明確選擇策略；跨磁碟搬移先複製及驗證，再刪來源。
- [ ] **FIL-005** 維運者可以修改擁有者、群組、Unix 權限與 ACL。 — 完成條件：遞迴操作先顯示範圍；不跟隨未授權連結越出目錄。
- [ ] **FIL-007** 使用者可以搜尋名稱、大小、時間及授權文字內容。 — 完成條件：搜尋有範圍、時間與資源上限；不能讀取無權目錄或無限制掃描整台主機。
- [ ] **FIL-009** 管理員可以設定可回收刪除與保留期限。 — 完成條件：同磁碟可移入受保護回收區；不支援回收時先告知，永不假裝可還原。
- [ ] **FIL-010** 使用者可以從容器掛載或備份頁直接開啟對應檔案位置。 — 完成條件：正確標示節點與實際路徑；網路 Volume 或叢集儲存無本機路徑時不製造假路徑。
- [ ] **FIL-011** 管理員可以建立有期限與範圍的分享連結，保留基線分享能力。 — 完成條件：預設不公開；可撤銷，下載需重新驗證範圍；不提供任意 root 檔案分享。
- [ ] **FIL-013** 使用者可以查看文字檔歷史、比較及回復指定版本。 — 完成條件：沿用基線檔案歷史能力；復原會建立新版本，不能蓋掉後續修改而不提醒；歷史中的秘密同樣保護。
- [ ] 以已核對的目錄控制代碼操作，防止檢查後被換成連結
- [ ] 跨磁碟搬移先複製及驗證再刪來源
- [ ] （增補 03 ROB-007，擁有票 017）非 UTF-8 與含控制字元的檔名可以顯示、改名、下載並檢視原始位元組（驗收 T-163、T-175）。
- [ ] （增補 03 51.6）設計時決定並寫進本票：兩個只差在非法位元組、顯示相同的檔名如何區分。
