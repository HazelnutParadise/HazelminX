# 115 — 管理員可以在指定主機與磁碟建立物件儲存（預設 RustFS），管理 bucket 與限定範圍的金鑰，給應用用、當備份目的地，並接管或遷移既有 MinIO

**Epic:** 資料庫（`epic:database`）  
**User Story:** 除了資料庫，也能在面板上開物件儲存，給應用存檔案、當備份目的地，不必自己架 MinIO  
**Milestone:** M4 資料庫、AI、備份與監控  
**Blocked by:** 039, 040, 077, 109  
**規格章節:** 增補 08｜56｜既有 Compose 專案的部署相容、分支觸發與物件儲存  
**Issue:** [#131](https://github.com/HazelnutParadise/hazelminx/issues/131)  

## What it delivers

依增補 08 的 56.4：物件儲存以轉接層實作，第一個引擎 RustFS（Apache 2.0，1.0 已發布），以平台管理的容器跑在專用網路，端點只綁 127.0.0.1、對外經 Zentinel。Bucket 管理（公開／私有、配額、版本控制、生命週期）、限定 bucket 的存取金鑰、部署單元宣告依賴後自動發金鑰並注入 `HZX_S3_*`、物件瀏覽與分享連結、備份目的地直接選 bucket、既有 MinIO 唯讀接管與遷移。

## Acceptance criteria

- [ ] **OBJ-001**（增補 08）管理員可以在指定主機與磁碟建立物件儲存服務。 — 完成條件：以平台管理的容器執行，固定版本；專用網路；端點只綁 127.0.0.1，對外經 Zentinel。
- [ ] **OBJ-002**（增補 08）物件儲存以轉接層實作，第一個引擎是 RustFS。 — 完成條件：畫面與 API 不出現引擎專屬的概念；換引擎不改應用拿到的變數。
- [ ] **OBJ-003**（增補 08）管理員可以管理 bucket：公開或私有、配額、版本控制、生命週期。 — 完成條件：引擎不支援的功能顯示停用與原因；非空 bucket 刪除前列出物件數與大小並要求輸入名稱。
- [ ] **OBJ-004**（增補 08）管理員可以建立限定 bucket 與權限的存取金鑰。 — 完成條件：Secret 只顯示一次並存進機密庫；可以停用、輪換、設定到期日。
- [ ] **OBJ-005**（增補 08）部署單元可以宣告依賴 bucket，平台自動發金鑰並注入變數。 — 完成條件：金鑰只能用該 bucket；依賴邊進影響預覽。
- [ ] **OBJ-006**（增補 08）使用者可以瀏覽、上傳、下載、刪除物件，並產生有期限的分享連結。 — 完成條件：分頁與前綴搜尋；分享連結預設 1 小時、最長 7 天。
- [ ] **OBJ-007**（增補 08）備份目的地可以直接選平台的 bucket。 — 完成條件：備份到同主機的 bucket 時警告。
- [ ] **OBJ-008**（增補 08）主機上的既有 MinIO 唯讀接管，並可遷移到平台的物件儲存。 — 完成條件：逐 bucket 複製並比對物件數與大小；切換端點；舊服務保留 7 天。

## Acceptance tests

- **T-265** 在 hazel-tw-01 的 /mnt/ssd1 建立物件儲存 `media`，建 bucket `uploads` 與只能讀寫 `uploads` 的金鑰。 → 服務在 `hzx-objstore-media` 網路；端點綁 127.0.0.1；金鑰 Secret 只顯示一次；用這把金鑰存取別的 bucket 被拒絕。
- **T-266** shop 的 web 單元宣告依賴 `uploads`。 → 部署後容器拿到四個 `HZX_S3_*` 變數；web 接上 `hzx-objstore-media`；停止 media 的影響預覽列出 shop web。
- **T-267** 主機上有一個 MinIO 容器，裡面有 2 個 bucket，選遷移。 → MinIO 標「控制者：外部」；遷移後兩邊的物件數與大小一致，應用改用新端點，MinIO 保留 7 天後才可刪除。
