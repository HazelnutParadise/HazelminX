# 079 — 管理員可以隔離演練還原、預覽覆寫並還原到不同節點與磁碟

**Epic:** 備份與還原（`epic:backup`）  
**User Story:** 管理員可以備份並真正還原  
**Milestone:** M4 資料庫、AI、備份與監控  
**Blocked by:** 078 使用者可以備份應用、資料庫、目錄與平台設定，含一致性、多目的地、保留與加密  
**規格章節:** 27｜備份內容、一致性、保留與還原、39｜跨功能流程：從按鈕到真正完成  
**Issue:** [#78](https://github.com/HazelnutParadise/hazelminx/issues/78)  

## What it delivers

隔離網路與外部憑證、不發信不觸發 webhook、架構／版本／容量／UID／Port／依賴檢查、覆寫獨立批准、路徑與節點映射。

## Acceptance criteria

- [ ] **BKR-008** 管理員可以進行隔離還原演練。 — 完成條件：還原至獨立位置與網路，預設不發信、不觸發正式 webhook、不連回正式寫入服務。
- [ ] **BKR-009** 管理員可以還原到原節點或不同節點與磁碟。 — 完成條件：檢查架構、版本、容量、UID／GID、權限、Port、依賴與金鑰。
- [ ] **BKR-010** 管理員可以預覽還原將覆寫的內容。 — 完成條件：正式資料覆寫需要獨立批准；保留目前狀態的可行復原方式。

## Acceptance tests（第 42 章）

- **T-111** 平台備份在乾淨主機還原。 → 身分、設定、秘密與節點對帳完整，未確認不直接接管。
- **T-112** 還原應用到不同路徑、節點與使用者 ID。 → 提供映射並驗證權限及資料，不使用舊絕對路徑猜測。
- **T-113** 演練備份內有寄信與 Webhook 排程。 → 預設不對正式外部系統產生副作用。
