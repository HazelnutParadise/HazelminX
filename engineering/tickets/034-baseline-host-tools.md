# 034 — 維運者可以管理 FTP／SFTP、Fail2ban、防毒等基線工具

**Epic:** 主機管理（`epic:host`）  
**User Story:** 維運者可以管理作業系統  
**Milestone:** M1 單機主機管理  
**Blocked by:** 021 維運者可以搜尋、安裝、更新、移除套件並套用安全更新, 022 維運者可以管理 systemd 服務、計時器與其設定檔  
**規格章節:** 10｜主機、套件、服務與網路  
**Issue:** [#34](https://github.com/HazelnutParadise/hazelminx/issues/34)  

## What it delivers

與 1Panel 基線對照的安裝、設定、紀錄與失敗處理；明確標示外部工具與所需套件。

## Acceptance criteria

- [ ] **SYS-011** 維運者可以管理 FTP／SFTP、Fail2ban、防毒等基線既有工具。 — 完成條件：OSS 已有功能逐一保留；明確標示外部工具與所需套件，不把 SFTP 混稱 FTP。
- [ ] **F2B-001**（增補 09）維運者可以看到每台主機的 Fail2ban 狀態，沒安裝時可以安裝。 — 完成條件：顯示服務狀態、版本、jail 數、目前封鎖數；安裝前列出會裝的套件；寫入記帳本。
- [ ] **F2B-002**（增補 09）維運者可以管理多個 jail 與全域預設值。 — 完成條件：涵蓋 57.3 表中所有欄位，以 1Panel 的封鎖時長、最大嘗試、比對時間、日誌路徑、受保護 Port 為下限；平台設定只寫 `.local` 與 `jail.d/`。
- [ ] **F2B-003**（增補 09）套用前先檢查，失敗不影響執行中的設定。 — 完成條件：`fail2ban-client -t` 失敗時不重新載入並顯示檔名與行號；重新載入失敗自動回到上一版；每次套用是可比較、可回到的版本。
- [ ] **F2B-004**（增補 09）封鎖方式跟平台負責寫入的防火牆一致。 — 完成條件：依 ROB-014 選定的防火牆決定 banaction；兩者不一致時標出並提供改正。
- [ ] **F2B-005**（增補 09）平台提供 Zentinel、管理入口與 recidive 的 jail。 — 完成條件：Zentinel jail 封鎖真實來源 IP；經 Tunnel 的流量改由 Zentinel 封鎖並說明原因。
- [ ] **F2B-006**（增補 09）自訂篩選規則可以先試跑。 — 完成條件：用最近 1,000 行日誌試跑，顯示命中數與前 20 個範例。
- [ ] **F2B-007**（增補 09）允許清單自動包含操作者來源與管理路徑，套用前擋下會把自己鎖在外面的設定。 — 完成條件：自動加入的項目標原因；移除時警告；57.4 的情況套用前擋下。
- [ ] **F2B-008**（增補 09）所有封鎖放在同一張清單，可以解封、延長、改永久、跨主機同步。 — 完成條件：來源、原因、剩餘時間；解封可選單台或全部；跨主機同步預設關，開啟後經工作送出；保留 30 天歷史。
