# 053 — 管理員可以編輯、更新與卸載商店應用，自訂設定不被新版覆寫

**Epic:** 應用商店（`epic:appstore`）  
**User Story:** 管理員可以用商店部署應用  
**Milestone:** M2 容器、Compose 與 GitHub  
**Blocked by:** 052 管理員可以同步官方商店並安裝整套應用，選擇節點、網路、Port 與資料位置, 046 管理員可以查看部署版本、三方比較並回到相容舊版  
**規格章節:** 16｜應用商店、範本與更新  
**Issue:** [#53](https://github.com/HazelnutParadise/hazelminx/issues/53)  

## What it delivers

安裝後完整編輯仍保留版本追蹤、只改計畫內映像版本、新版範本差異預覽與衝突、卸載保留或刪除資料（只刪明確擁有的資源）、商店離線時既有應用可管理。

## Acceptance criteria

- [ ] **APP-005** 管理員可以完整編輯安裝後設定。 — 完成條件：修改後仍保留商店版本追蹤、備份與更新能力，不必選擇「自訂」才避免覆寫。
- [ ] **APP-006** 管理員可以更新應用映像。 — 完成條件：一般更新只改計畫內服務版本；必要設定與資料變更另外列出並驗證。
- [ ] **APP-007** 管理員可以預覽新版範本變更。 — 完成條件：原掛載、網路、環境變數、資源限制不被預設值取代；衝突進入待處理。
- [ ] **APP-008** 管理員可以卸載應用並選擇保留或刪除資料。 — 完成條件：預設保留；刪除只包含此應用明確擁有的資源，外部網路與 Volume 不連帶刪除。
- [ ] **APP-010** 管理員可以在來源暫時失效時管理既有應用。 — 完成條件：已安裝服務不因商店 API 離線停止；固定範本及映像資料可用於復原。
- [ ] 卸載與其他應用共用的資料庫時顯示相依，不誤刪外部共用實例

## Acceptance tests（第 42 章）

- **T-057** 商店升級應用，已自訂 network、port 與資料碟。 → 除批准版本差異外完全保留，沒有預設覆寫。
- **T-065** 解除安裝與其他應用共用的資料庫。 → 顯示相依關係，不能誤刪外部共用實例。
