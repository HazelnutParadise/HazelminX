# 021 — 維運者可以搜尋、安裝、更新、移除套件並套用安全更新

**Epic:** 主機管理（`epic:host`）  
**User Story:** 維運者可以管理作業系統  
**Milestone:** M1 單機主機管理  
**Blocked by:** 019 管理員可以用一次性註冊碼加入節點，並看到離線、過期、維護與撤銷狀態, 012 維運者可以執行需要高權限的固定動作，而 Agent 主程序維持低權限  
**規格章節:** 10｜主機、套件、服務與網路  
**Issue:** [#21](https://github.com/HazelnutParadise/hazelminx/issues/21)  

## What it delivers

apt／dnf 適配：相依與會移除的套件、磁碟需求、需重啟服務、套件鎖等待、原始紀錄、維護時段、套件來源與簽章狀態。

## Acceptance criteria

- [ ] **SYS-002** 維運者可以搜尋套件、查看版本、安裝、更新與移除。 — 完成條件：顯示相依套件、會移除的套件、磁碟需求及需重啟的服務；使用對應發行版套件工具。
- [ ] **SYS-003** 維運者可以套用安全更新並設定維護時段。 — 完成條件：套件鎖被占用時等待或退出，不殺掉其他套件管理程序；失敗能看到套件工具原始紀錄。
- [ ] **SYS-012** 維運者可以查看套件來源及其簽章狀態。 — 完成條件：新增來源前顯示網域、簽章金鑰與影響；不自動信任未知來源。
- [ ] 套件鎖被占用時等待或明確失敗，不殺掉對方程序或刪鎖檔
- [ ] 新增來源前顯示網域、簽章金鑰與影響

## Acceptance tests（第 42 章）

- **T-007** 套件管理器正被其他工作使用。 → 等待或明確失敗，不殺掉對方程序或刪鎖檔。
