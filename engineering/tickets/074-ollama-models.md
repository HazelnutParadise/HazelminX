# 074 — 管理員可以安裝或接管 Ollama 並管理模型的下載、刪除、複製與配額

**Epic:** AI 與模型（`epic:ai`）  
**User Story:** 管理員可以管理模型與推論服務  
**Milestone:** M4 資料庫、AI、備份與監控  
**Blocked by:** 052 管理員可以同步官方商店並安裝整套應用，選擇節點、網路、Port 與資料位置  
**規格章節:** 25｜AI 管理、Ollama 與模型  
**Issue:** [#73](https://github.com/HazelnutParadise/hazelminx/issues/73)  

## What it delivers

節點與資料位置選擇、接管不重下載、模型清單與下載進度／磁碟預檢／取消、模型來源搜尋（不虛構清單）、載入卸載、digest 與配額、更新保留模型與自訂 Compose。

## Acceptance criteria

- [ ] **AI-001** 管理員可以選節點與資料位置安裝 Ollama 容器。 — 完成條件：容器、Port、網路、模型磁碟與資源設定可預覽；預設不公開無驗證 API。
- [ ] **AI-002** 管理員可以接管現有 Ollama。 — 完成條件：不重新下載或刪除模型；確認服務版本與 API 能力後才操作。[S15](#source-S15)
- [ ] **AI-003** 使用者可以列出、下載、刪除、複製與查看模型資訊。 — 完成條件：下載有實際進度、磁碟預檢與取消結果；失敗不把未完成模型標成可用。
- [ ] **AI-004** 使用者可以搜尋可用模型來源。 — 完成條件：官方目錄 API 不可用時提供指定模型名稱與可查證來源，不虛構完整即時模型清單。
- [ ] **AI-005** 使用者可以載入、卸載及測試模型。 — 完成條件：顯示實際載入狀態與推論錯誤；卸載記憶體不誤當刪除磁碟檔案。
- [ ] **AI-008** 管理員可以管理模型來源、授權、digest 與磁碟配額。 — 完成條件：同名模型更新有紀錄；模型未使用不代表可未經確認自動刪除。
- [ ] **AI-010** 管理員可以更新 Ollama 而保留模型及自訂 Compose。 — 完成條件：更新前後核對模型清單、資料位置與推論；不重新生成既有使用者密鑰。

## Acceptance tests（第 42 章）

- **T-104** 模型下載中斷、空間不足與取消。 → 進度與錯誤正確；保留可續接部分或安全清理。
- **T-105** 更新 Ollama 的容器映像。 → 模型資料、GPU、Port、自訂網路與掛載保持。
