# 083 — 管理員可以匯出匯入設定、收發整合 Webhook，並用 CLI 查看版本、診斷與升級

**Epic:** API、CLI 與整合（`epic:integration`）  
**User Story:** 整合者可以用同一套規則操作平台  
**Milestone:** M4 資料庫、AI、備份與監控  
**Blocked by:** 010 整合者可以用 /management/v1 的分頁、版本條件與工作回應操作資源, 016 管理員可以預覽並批准高風險變更計畫，內容改變時原批准失效  
**規格章節:** 30｜API、CLI、MCP 與外部整合  
**Issue:** [#82](https://github.com/HazelnutParadise/hazelminx/issues/82)  

## What it delivers

CLI 與 Web UI 同一工作邏輯、整合 Webhook 驗證與出站範圍限制、匯出格式版本與遮罩、匯入乾跑、adapter 能力宣告、停用整合撤銷權杖。

## Acceptance criteria

- [ ] **INT-002** 管理員可以以 CLI 查看版本、診斷、升級與復原。 — 完成條件：與 Web UI 使用相同工作邏輯；離線救援只做明確授權的本機操作。
- [ ] **INT-005** 管理員可以接收及發出整合 Webhook。 — 完成條件：驗證簽章、限制大小、去重、重試與敏感欄位；出站位址受範圍限制。
- [ ] **INT-006** 管理員可以匯出專案、範本與設定。 — 完成條件：格式有版本，預設不含明文秘密；匯入先乾跑，不直接改正式資源。
- [ ] **INT-007** 維護者可以加入新儲存、引擎或監控 adapter。 — 完成條件：有能力宣告、版本、測試與授權；任意外掛不得預設在 Core root 權限內執行。
- [ ] **INT-008** 管理員可以停用不需要的整合。 — 完成條件：停用後撤銷相關權杖與回呼，既有應用不因移除無關整合被刪除。
- [ ] **DAT-007** 管理員可以匯出自己的設定與資料。 — 完成條件：可讀格式含版本與文件；機密預設遮罩，需要另外授權匯出。
- [ ] **SEC-007** 系統可以限制敏感的出站連線。 — 完成條件：URL、Webhook、下載及代理目標不能任意連雲端中繼資料位址或管理 Socket；必要內網來源以資源範圍授權。
- [ ] 出站 URL 不能連雲端中繼資料位址或管理 Socket
