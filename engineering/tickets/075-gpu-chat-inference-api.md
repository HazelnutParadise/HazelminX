# 075 — 管理員可以選 GPU、在網頁測試模型，並透過 Token 代理發布推論 API

**Epic:** AI 與模型（`epic:ai`）  
**User Story:** 管理員可以管理模型與推論服務  
**Milestone:** M4 資料庫、AI、備份與監控  
**Blocked by:** 074 管理員可以安裝或接管 Ollama 並管理模型的下載、刪除、複製與配額, 062 管理員可以發布 infra-manager 相容的 Token API 代理，既有客戶端不需修改  
**規格章節:** 25｜AI 管理、Ollama 與模型  
**Issue:** [#74](https://github.com/HazelnutParadise/hazelminx/issues/74)  

## What it delivers

驅動／容器工具／裝置權限／實際推論檢查、GPU 驅動變更需批准、串流聊天測試（取消釋放資源、輸出只是資料）、Token 代理限速與並行、多節點模型標示與複製。

## Acceptance criteria

- [ ] **AI-006** 管理員可以選擇 CPU 或可用 GPU。 — 完成條件：檢查驅動、容器工具、裝置權限與實際推論；看見 GPU 不等於容器可以使用。[S30](#source-S30)
- [ ] **AI-007** 使用者可以在網頁聊天、串流測試與查看必要效能資訊。 — 完成條件：取消時釋放資源；模型輸出的 HTML／指令只是資料，不自動執行。
- [ ] **AI-009** 管理員可以透過 Token 代理發布推論 API。 — 完成條件：身分、速率、上傳大小與並行限制有效；伺服器管理權與模型使用權分開。
- [ ] **AI-011** 管理員可以管理多節點的模型與推論服務。 — 完成條件：每個模型清楚標示節點；跨節點下載與複製有進度，不假設模型已存在所有節點。

## Acceptance tests（第 42 章）

- **T-103** Ollama GPU 不可用或驅動不相容。 → 預檢說明缺項，不把 CPU 執行假裝 GPU 成功。
