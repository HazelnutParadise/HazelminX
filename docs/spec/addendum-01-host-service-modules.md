# 規格增補 01｜宿主機服務模組（Webmin 等價）

- 狀態：已核定（2026-11-07，使用者決定「納入」）。
- 位置：接在 v1.1 規格第 48 章之後，章節編號 49。v1.1 原檔與 `SHA256SUMS.txt` 不動；需求 ID 以 `HSM-` 開頭，驗收案例 `T-140` 起。
- 範圍：Webmin 2.x 有、v1.1 規格沒要求的九類模組。目標是「完全取代 Webmin」時不留洞。

## 49.1 為什麼要一個通用框架

這九類模組的共同形狀都是「宿主機上的一個 systemd 服務＋一組設定檔＋一些狀態」。Webmin 每個模組各寫一套；我們用一個框架承載，每個模組只提供：設定檔的結構化對映（欄位 ↔ 檔案片段）、套用前驗證指令、重載指令、狀態來源。框架負責：讀取、結構化編輯與原始編輯切換（UI-008）、套用前驗證、版本與回滾（FIL-013）、高權限執行（SEC-005／006）、工作化（33 章）。

## 49.2 要求

| ID | 誰可以做什麼與必要行為 | 可檢驗的完成條件 |
|---|---|---|
| HSM-001 | 維運者可以在「服務模組」頁看到每個節點上各模組的安裝、執行、版本與設定檔是否通過驗證。 | 未安裝與已安裝未啟用分開顯示；驗證失敗列出指令原始輸出。 |
| HSM-002 | 維運者可以用結構化表單或原始檔編輯模組設定，套用前先跑該模組的驗證指令。 | 驗證失敗不寫入；不認識的合法指令原樣保留；每次套用留版本可回滾。 |
| HSM-003 | 維運者可以安裝、啟用、停用、移除模組對應的套件與服務。 | 走套件管理（SYS-002）與 systemd（SYS-004）；移除前列出仍引用的設定與資料。 |
| HSM-004 | 維運者可以管理 BIND 權威 DNS：zone、紀錄（A／AAAA／CNAME／MX／TXT／SRV／PTR）、序號、轉送。 | 寫入前 `named-checkzone`／`named-checkconf` 通過；序號自動遞增；可比對實際解析結果。 |
| HSM-005 | 維運者可以管理 DHCP（ISC／Kea）：子網、範圍、固定分配、選項，並查看租約。 | 設定檔驗證通過才重載；租約表可搜尋 MAC／IP／主機名。 |
| HSM-006 | 維運者可以管理 Postfix／Dovecot：網域、信箱、別名、轉寄、TLS、佇列。 | 佇列可查看、重送、刪除；TLS 憑證可沿用 Zentinel 的憑證；不把密碼寫進變更紀錄。 |
| HSM-007 | 維運者可以管理 Samba 分享與 NFS exports（伺服器端）。 | 分享路徑、權限、允許來源逐項顯示；`testparm`／`exportfs -r` 驗證通過才套用；列出目前連線。 |
| HSM-008 | 維運者可以管理宿主機原生的 Apache／Nginx：虛擬主機、模組、設定檔。 | 與 Zentinel 的責任分工明寫（誰終止 TLS、誰對外）；Port 衝突在套用前檢查；`apachectl configtest`／`nginx -t` 通過才重載。 |
| HSM-009 | 維運者可以管理 logrotate：每組日誌的輪替頻率、保留數、壓縮、輪替後動作。 | 可乾跑（`logrotate -d`）看結果；不影響平台自己的日誌保留政策（35 章）。 |
| HSM-010 | 維運者可以管理磁碟配額：每個檔案系統啟用配額、每使用者／群組的軟硬限制與寬限。 | 顯示目前用量對限制；檔案系統未啟用配額時說明要怎麼啟用（重新掛載）。 |
| HSM-011 | 維運者可以查看與編輯 PAM 服務設定與 MIME 類型對映。 | 編輯 PAM 前顯示影響的登入方式與鎖死風險；保留救援路徑（IAM-008）。 |
| HSM-012 | 維運者可以管理 CUPS 印表機：新增、佇列、暫停、預設。 | 未安裝 CUPS 時顯示安裝入口而不是空頁。 |
| HSM-013 | 每個模組的操作都走工作引擎與高權限執行器，具名動作，不開任意 shell。 | 參數安全（SEC-006）測試涵蓋每個模組的路徑與名稱欄位。 |
| HSM-014 | 模組可由維護者以 adapter 新增（INT-007）。 | 新模組只需提供對映、驗證、重載、狀態四件事；文件列出範本。 |

## 49.3 驗收案例

| 編號 | 情境 | 通過條件 |
|---|---|---|
| T-140 | 在 BIND 新增一筆 A 紀錄並套用。 | checkzone 通過、序號遞增、`dig` 查到新值；回滾到上一版後查不到。 |
| T-141 | 寫錯 DHCP 子網遮罩。 | 驗證失敗、不重載、原始錯誤可見、舊設定仍在服務。 |
| T-142 | Postfix 佇列卡 50 封信。 | 可列出、重送、刪除；操作在稽核紀錄。 |
| T-143 | 新增 Samba 分享到不存在的路徑。 | 套用前擋下並說明；不寫入 smb.conf。 |
| T-144 | Nginx 虛擬主機要綁 443 而 Zentinel 已占用。 | 套用前 Port 衝突擋下，提示改走 Zentinel 站點或換 Port。 |
| T-145 | logrotate 乾跑。 | 顯示會輪替哪些檔與保留幾份，不實際動檔案。 |
| T-146 | 使用者超過配額軟限制。 | 配額頁標示超限與寬限剩餘時間。 |
| T-147 | 編輯 PAM sshd 把自己鎖在外面。 | 套用前警告並要求確認救援路徑存在；Agent 通道不受 sshd 影響。 |
| T-148 | 模組套件未安裝。 | 頁面顯示安裝入口與需要的套件，不顯示空表。 |

## 49.4 不納入的部分

Webmin 的 Perl 模組管理、Java 檔案管理器、HTTP tunnel、Usermin 不納入；Webmin 的 Apache 模組清單裡與 1Panel OpenResty 重疊的站點功能以 Websites 頁為準。
