# 邊界情境目錄（2026-11-07）

規則：不假設使用者照我們的流程走。每個情境寫「會發生什麼、畫面怎麼呈現、哪些規則」，對應畫板 `EdgeCases`（12 張卡）與各頁。資料來源：規格 40 章失敗情境、Nielsen 錯誤預防與復原、1Panel／Portainer issue 常見抱怨。

| 情境 | 畫面怎麼做 | 規則寫在哪 |
|---|---|---|
| 1,000+ 容器、50+ 節點 | 表格虛擬捲動＋每頁 50＋篩選進網址；容器地圖超過 300 格改「節點 × 狀態」摘要格；拓撲每欄超過 6 個折成「＋N」 | DESIGN.md 表格、拓撲；UI-012 |
| 超長名稱、路徑、映像 tag | 名稱欄最多兩行可斷行；不用省略號吃掉尾端；完整值在 title 與詳情 | DESIGN.md Layout |
| 並行編輯衝突（兩人、或同帳號兩個分頁） | 寫入帶版本條件；衝突 banner＋看差異／覆蓋／放棄；另一分頁開著時提示 | 規格 34 章；EdgeCases |
| 權限不足 | 按鈕不藏，點了 403 寫明角色與動作；可一鍵建立變更計畫請擁有者批准；API 同樣拒絕 | IAM-001；EdgeCases |
| 操作做到一半失敗 | 流程段標出失敗步驟與結束碼；列出「已建立／未建立」；提供重試、清掉已建立、保留現狀三個動作 | 33 章工作引擎；WorkCenter |
| 時鐘偏差、節點時區不同 | 偏差 banner；所有時間帶時區；排程頁同時列節點時區與使用者時區 | JOB-011；Cron |
| 上傳中斷、瀏覽器重新整理 | 分片存 Agent 暫存 24 小時；續傳從分片 N 開始；關頁不取消伺服器端工作 | FIL-003、UI-003 |
| 磁碟滿 | 寫入失敗 banner 寫出哪個掛載點；平台資料庫在別的磁碟時說明不受影響；動作：清理可回收、停寫入最多的容器、搬移 | STO-010；Storage |
| API 逾時、批次部分失敗 | 逐節點列結果：成功／失敗／未回應三種，不把未回應算失敗；可改成背景工作 | UI-009、ENG-008 |
| 不認識的引擎版本、compose 欄位 | 版本不在驗證矩陣：只開讀取與升級，建立／刪除先拒絕並說明；不認識的欄位原樣保留 | NOD-011、UI-008 |
| 刪除仍被引用的資源 | 刪除鈕停用並列出引用者（應用、備份任務、入口） | 規格 43 章追蹤表 |
| 節點離線時的操作 | 終端機、檔案、系統頁顯示「上次觀測」並停用寫入；提供 SSH 備援；離線期間的本地排程照政策續跑 | NOD-007、JOB-012 |
| 空資料 vs 載入 vs 錯誤 vs 部分 | States 畫板：骨架、空（含怎麼開始）、四段式錯誤、部分結果（標 * 與完整度）、離線保留上次渲染 | UI-007 |
| 未知總量 | 不顯示百分比，只顯示已完成量；不可取消的步驟寫明原因（固定模板） | ENG-007 |
| 鍵盤與螢幕閱讀器 | 所有可點元素是真 button／a／input；焦點環 2px；列尾動作有 aria-label；表格有勾選欄與全選 | UI-005、T-117 |
| 360px 與 1920px | 六種寬度掃描零溢出；矩陣與熱格橫向捲動；拓撲固定尺寸捲動；1920 以上 .cg 自動三欄 | DESIGN.md Layout |

未畫、記票：加入節點等待連線（019）、容器詳情（040）、登入與鎖定畫面（009／017）。
