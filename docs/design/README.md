# 設計過程檔（票 002）

這個目錄放設計階段的工作檔。專案根目錄的 `DESIGN.md` 才是視覺基準；它在三個方向中選定一個後才建立。

| 檔案 | 內容 |
|---|---|
| `design-brief.md` | 三個方向的共同輸入：產品、讀者、核心資訊、主導覽、情感基調、硬性限制、示例資料 |
| `directions/a-starchart.dc.html` | 方向 A「星圖」：風格輪盤抽到「復古未來太空圖錄」。奶油紙底、墨黑、鈷藍；襯線只用在標題；左側窄欄導覽 |
| `directions/b-terminal.dc.html` | 方向 B「航站」：現實標竿是 Linear 類鍵盤優先工具。深暖炭黑底、榛果色單一強調；三欄（導覽／主表／需要處理） |
| `directions/c-hazelnut.dc.html` | 方向 C「榛果」：Stripe 設計團隊式「讓人信任的密集介面」。米白底、榛果棕強調、水平頂導覽、卡片網格 |
| `directions/canvas.json` | Claude Design 畫布的索引（三個畫板的位置與便利貼） |

三個檔案是 Claude Design 畫布的畫板格式（`.dc.html`）：一般 HTML 加上 `<x-dc>`、`<helmet>` 與 `{{theme}}` 主題切換。要在瀏覽器直接看，拿掉 `support.js`、`<x-dc>`、`<helmet>` 標籤並把 `{{theme}}` 換成 `light` 或 `dark` 即可。

畫布連結：<https://claude.ai/artifact/NBXgFGYEiZVnKLraoa7Nt8>（私人，需擁有者分享）。

## 三版共同遵守的規則

- 同一組示例資料（標示為假設），只換骨架與視覺。
- 狀態不只靠顏色：連線中是實心圓、過期是空心圓、維護中是方形，並配文字。
- 錯誤與待辦都是四段式：發生什麼、影響什麼、證據、下一步。
- 離線不等於應用已停止；過期資料標示「上次觀測」與時間。
- 未知總量不顯示假百分比；不可取消的步驟寫明原因。
- 淺色與深色都設計，由 `dark`／`light` 切換。
- 360px 寬：導覽改橫向可捲動或換行、次要欄位隱藏、表格橫向捲動；觸控目標 ≥ 36–44px。

## 下一步

4. 設計審查記錄於 `DESIGN-REVIEW.md`。
