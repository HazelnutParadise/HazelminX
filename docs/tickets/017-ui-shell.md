## What it delivers

7.1 的主導覽、資源永久識別碼的跨頁連結、工作中心與事件串流接續、權限過濾搜尋、載入／空／錯誤／部分／離線狀態元件、錯誤四段式呈現、大型表格與日誌的虛擬捲動與取消查詢。

## Acceptance criteria

- [ ] **UI-002** 使用者可以在服務頁直接查看節點、引擎、連接埠、網域、資料、日誌與版本。 — 完成條件：不必複製容器 ID 到其他頁手動搜尋才能完成基本工作。
- [ ] **UI-003** 使用者可以從任何頁面回到進行中的工作。 — 完成條件：重新整理或關閉瀏覽器不取消伺服器端任務；重新登入可接續看進度。
- [ ] **UI-004** 使用者可以搜尋自己有權限的資源。 — 完成條件：搜尋不洩漏無權查看的名稱、IP、機密或節點存在與否。
- [ ] **UI-007** 使用者可以知道載入、空資料、錯誤、部分結果與離線的差別。 — 完成條件：沒資料不能顯示成零；過期資料顯示觀測時間；錯誤保留輸入內容。
- [ ] **UI-011** 使用者可以讀懂主要錯誤，不需先懂錯誤代碼。 — 完成條件：顯示「發生什麼、影響什麼、證據、下一步」；底層日誌可展開。
- [ ] **UI-012** 使用者操作大型表格與日誌時不會讓整頁失去回應。 — 完成條件：分頁或虛擬捲動；可取消查詢；有資料量與截斷提示；保留篩選狀態。
- [ ] 重新整理或關閉瀏覽器不取消伺服器端任務；重新登入可接續看進度
- [ ] 搜尋不洩漏無權查看的名稱、IP 或節點存在與否
- [ ] 對話框依 DESIGN.md「對話框關閉規則」：有輸入或未儲存變更時點背景不關閉，Esc 與關閉鈕改問「儲存／不儲存／取消」；執行中不可中斷的對話框沒有關閉，只能「在背景繼續」到工作中心。
- [ ] **ROB-004**（增補 03）使用者可以知道平台與各節點目前是否降級，以及還能做什麼。 — 完成條件：依機制四的表與預設門檻進入與解除；平台層級出現頂端降級列，節點與引擎環境層級只出現在該節點頁與相關資源狀態條；不能做的動作停用並寫出原因。
- [ ] **ROB-005**（增補 03）管理員可以為節點與專案環境標示用途等級（沿用 34.1 的正式／測試，另加實驗）。 — 完成條件：有效等級依機制三計算，顯示在頁面標題區、資源狀態條與終端機分頁；既有高風險確認框對正式等級資源寫出等級與目標名稱；未標示時不顯示徽章。
- [ ] **ROB-007**（增補 03）使用者看到的名稱類欄位完整且安全。 — 完成條件：控制字元以可見符號顯示；非 UTF-8 檔名可以顯示、改名、下載並檢視原始位元組；超長名稱換行不截斷。
- [ ] **ROB-008**（增補 03）每個列表與查詢宣告其邊界，並在超出時說明。 — 完成條件：`/management/v1` 列表回應的中繼資料與 UI 表格底部寫出每頁筆數、查詢上限、逾時；超過上限顯示「已顯示 N／總數 M」；逾時顯示「總數未知」，保留已取得部分並可改成背景工作。
- [ ] 資源狀態條（控制者、接管狀態、漂移、觀測時間、鎖、用途等級）、影響預覽、降級列、用途等級徽章是共用元件，所有資源頁面與列表使用同一組元件（增補 03 51.1）。

## Acceptance tests（第 42 章）

- **T-119** 資源與日誌數量達壓測規模。 → 分頁、取消、搜尋、事件串流仍符合目標。
- **T-160** 平台資料庫變成唯讀。 → 出現頂端降級列。可以登入；寫入按鈕停用並寫出原因；可以下載診斷包；稽核寫入本機附加檔，資料庫恢復後補回。
- **T-161** 節點標正式、專案環境標測試，對該專案環境部署。 → 有效等級為正式；部署確認框寫出「正式」與專案環境、節點名稱。
- **T-163** 資料夾裡有非 UTF-8 檔名。 → 可以列出、改名、下載，並可檢視原始位元組。
- **T-164** 查詢 1 萬筆容器事件時逾時。 → 顯示已取得筆數與「總數未知」；改成背景工作後，在工作中心看到完整結果。
- **T-171** 100 台節點中有 1 台離線。 → 不出現頂端降級列；該節點頁顯示離線、對它的寫入停用；其他節點不受影響。
- **T-174** 從終端機開啟一台標為正式的節點。 → 終端機分頁顯示正式等級徽章。
- **T-175** 容器名含控制字元，另一個容器名長達 200 字元。 → 控制字元以可見符號顯示；長名稱完整換行，不截斷。
