## What it delivers

7.1 的主導覽、資源永久識別碼的跨頁連結、工作中心與事件串流接續、權限過濾搜尋、載入／空／錯誤／部分／離線狀態元件、錯誤四段式呈現、大型表格與日誌的虛擬捲動與取消查詢。

## Acceptance criteria

- [ ] **UI-002** 使用者可以在服務頁直接查看節點、引擎、連接埠、網域、資料、日誌與版本。 — 完成條件：不必複製容器 ID 到其他頁手動搜尋才能完成基本工作。
- [ ] **UI-003** 使用者可以從任何頁面回到進行中的工作。 — 完成條件：重新整理或關閉瀏覽器不取消伺服器端任務；重新登入可接續看進度。
- [ ] **UI-004** 使用者可以搜尋自己有權限的資源。 — 完成條件：搜尋不洩漏無權查看的名稱、IP、機密或節點存在與否。
- [ ] **UI-007** 使用者可以知道載入、空資料、錯誤、部分結果與離線的差別。 — 完成條件：沒資料不能顯示成零；過期資料顯示觀測時間；錯誤保留輸入內容。
- [ ] **UI-011** 使用者可以讀懂主要錯誤，不需先懂錯誤代碼。 — 完成條件：顯示「發生什麼、影響什麼、證據、下一步」；底層日誌可展開。
- [ ] **UI-012** 使用者操作大型表格與日誌時不會讓整頁失去回應。 — 完成條件：分頁或虛擬捲動；可取消查詢；有資料量與截斷提示；保留篩選狀態。
- [ ] 重新整理或關閉瀏覽器不取消伺服器端任務；重新登入可接續看進度
- [ ] 搜尋不洩漏無權查看的名稱、IP 或節點存在與否
- [ ] 對話框依 DESIGN.md「對話框關閉規則」：有輸入或未儲存變更時點背景不關閉，Esc 與關閉鈕改問「儲存／不儲存／取消」；執行中不可中斷的對話框沒有關閉，只能「在背景繼續」到工作中心。
