## What it delivers

Agent 收集 CPU 每核心、記憶體、swap、負載、磁碟 I/O 與健康、網路、溫度、GPU（NVIDIA／AMD／Intel 依驅動能力）；Core 保存有解析度的歷史；主機頁顯示 OS、核心、架構、開機時間、時區與時間同步。

## Acceptance criteria

- [ ] **SYS-001** 維運者可以查看 OS、核心、架構、開機時間、時區與時間同步狀態。 — 完成條件：來源與更新時間可查；未知欄位顯示未提供，不填零或猜測。
- [ ] **MON-001** 使用者可以看 CPU 每核心、記憶體、swap、負載、磁碟與網路。 — 完成條件：指標單位、採樣時間與來源固定；快取記憶體不誤算成完全不可用。
- [ ] **MON-002** 使用者可以看 GPU 型號、記憶體、使用率、溫度、功耗與程序。 — 完成條件：依 NVIDIA／AMD／Intel 驅動實際能力提供，缺值明示，不假造跨廠相同欄位。
- [ ] **MON-003** 使用者可以看磁碟延遲、I/O、容量與健康。 — 完成條件：區分實體磁碟、RAID、虛擬碟與網路掛載；USB bridge 不提供 SMART 時明示。
- [ ] **MON-005** 使用者可以查看即時與歷史趨勢。 — 完成條件：缺少資料保留缺口；歷史彙總標示解析度，不用補零製造跌幅。
- [ ] 缺值明示未提供，不填零；歷史缺口保留缺口
- [ ] USB bridge 不提供 SMART 時明示
- [ ] GPU 欄位對齊 1Panel v2.4.1 `agent/utils/ai_tools/gpu/types.go`：效能狀態（P-state）、時脈（核心、顯示記憶體、媒體）、降頻原因、PCIe 世代與寬度、功耗（目前、上限、預設、最大）、溫度（核心、熱點、顯示記憶體）、風扇、顯示記憶體（已用、可用、保留）、引擎使用率（編碼、解碼、JPEG、OFA）、ECC 模式與錯誤、持久模式、運算模式、MIG、UUID、Bus ID；驅動不提供的欄位寫「不提供」。
- [ ] 正在使用 GPU 的程序列出 PID、程序、類型、顯示記憶體、核心使用率，並以 cgroup 對回所屬容器（Docker、Podman、K8s Pod），主機程序標「主機」；容器列表顯示每個容器目前的 GPU 使用率與顯示記憶體。
- [ ] 節點硬體依類別分組成卡片（CPU、記憶體、磁碟、GPU、網卡、溫度），一組超過 4 個改依使用率排序的精簡橫條並收合其餘；溫度列出所有讀得到的感測器（hwmon、smartctl／nvme、NVML、IPMI），以各自臨界溫度畫比例並標來源（畫板 NodeDetail「硬體」）。
