# 066 — 使用者可以依時間、節點、網域與入口查看流量、來源、路徑、裝置與 API 用量

**Epic:** 流量分析（`epic:analytics`）  
**User Story:** 使用者可以理解流量來源  
**Milestone:** M3 網站入口與安全防護  
**Blocked by:** [065 管理員可以為每個入口設定可信代理模式，Cloudflare Tunnel 流量取得正確訪客 IP](065-trusted-ip-tunnel.md), [035 管理員可以設定日誌與統計容量、保存政策並產生遮罩診斷包](035-logs-retention-diagnostics.md)  
**Status:** blocked  
**規格章節:** 23｜流量分析、網站來源與 API 用量  
**Issue:** [#65](https://github.com/HazelnutParadise/hazelminx/issues/65)  

## What it delivers

分段事件儲存與摘要、指標定義、地理與 ASN（版本與推估性質）、Referer、路徑正規化與遮罩、UA 推估、API 用量（請求與模型 token 分開）、請求關聯碼、保留與遮罩設定、完整度計數、延遲分段、異常流量頁建立政策。

## Acceptance criteria

- [ ] **ANA-001** 使用者可以依時間、節點、專案、網域、服務及入口看流量。 — 完成條件：顯示請求數、位元組、錯誤率、延遲分布與資料時間；指標定義可查看。
- [ ] **ANA-002** 使用者可以看來源國家、ASN、網路業者與可信 IP。 — 完成條件：地理資料版本與推估性質明示；未知位置不填成某個國家。
- [ ] **ANA-003** 使用者可以看推薦網站、搜尋來源與直接／未知來源。 — 完成條件：Referer 缺失或被隱私機制移除時不宣稱已識別；預設移除敏感 query。
- [ ] **ANA-004** 使用者可以看熱門路徑、方法、回應碼與錯誤。 — 完成條件：路徑有正規化與敏感資料遮罩；不將含 Token 路徑永久記錄。
- [ ] **ANA-005** 使用者可以看裝置、瀏覽器與機器人推估。 — 完成條件：UA 可偽造的限制可見；不把粗略推估稱為精準真人統計。
- [ ] **ANA-006** 使用者可以看 API 使用者、Token 與服務用量。 — 完成條件：請求次數、傳輸量與模型 token 用量分開，不混用「Token」的兩種意思。
- [ ] **ANA-008** 使用者可以連結流量事件、WAF 事件與部署版本。 — 完成條件：以請求關聯碼追查，不需要從三種日誌手動猜同一請求。
- [ ] **ANA-009** 管理員可以設定保留期限、遮罩與匯出。 — 完成條件：原始 IP、詳細日誌與彙總統計可分開保留；刪除與容量限制可追蹤。
- [ ] **ANA-010** 使用者可以知道數據是否完整。 — 完成條件：延遲、取樣、重傳去重、遺失與截斷有計數；無流量與資料未到達有不同顯示。
- [ ] **ANA-011** 使用者可以看到可比較的延遲統計。 — 完成條件：分開來源站處理、上游回應與完整傳輸時間；不能拿平均值冒充 p95。
- [ ] **ANA-012** 管理員可以在異常流量頁建立安全政策。 — 完成條件：先顯示影響範圍、到期日與風險，避免把共同代理或 NAT 位址一鍵永久封鎖。
- [ ] 無流量與資料未到達顯示不同
- [ ] 不拿平均值冒充 p95
