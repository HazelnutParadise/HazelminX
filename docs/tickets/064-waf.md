# 064 — 安全管理員可以安裝 WAF，逐站設定模式、規則、例外與失效政策

**Epic:** WAF 與可信 IP（`epic:security`）  
**User Story:** 管理員可以保護網站與 API  
**Milestone:** M3 網站入口與安全防護  
**Blocked by:** [055 管理員可以從介面安裝原生 Zentinel，Core 重啟不影響既有網站，救援入口不依賴它](055-zentinel-install.md)  
**Status:** blocked  
**規格章節:** 21｜WAF、安全政策與防護失效  
**Issue:** [#63](https://github.com/HazelnutParadise/hazelminx/issues/63)  

## What it delivers

可替換 WAF 介面與候選引擎比較紀錄、規則包安裝與更新（失敗保留上一版）、偵測／阻擋模式、例外最小範圍、IP／地區／速率政策、body 界線、失效政策、健康與延遲、誤擋檢查、多節點逐步發布、到期、匯出、歧義請求拒絕。

## Acceptance criteria

- [ ] **WAF-001** 安全管理員可以逐網站／API 啟用關閉、只偵測或阻擋模式。 — 完成條件：畫面顯示實際模式與政策版本；只偵測不能標成已阻擋。
- [ ] **WAF-002** 管理員可以安裝與更新 WAF 元件及規則。 — 完成條件：引擎、規則與代理版本相容；先驗證候選政策，失敗保留上一版。
- [ ] **WAF-003** 管理員可以檢視規則、命中原因與最小範圍例外。 — 完成條件：能針對網域、路徑、參數或規則建立例外，不只能整站關閉防護。
- [ ] **WAF-004** 管理員可以設定 IP／CIDR、國家地區與速率政策。 — 完成條件：使用經驗證的訪客身分；IPv4／IPv6、未知地理位置及代理來源都有明確處理。
- [ ] **WAF-005** 管理員可以設定 body 大小、解壓縮與檢查界線。 — 完成條件：超限、壓縮炸彈、multipart 與串流不導致無上限記憶體；未檢查部分明示。
- [ ] **WAF-006** 管理員可以選擇 WAF 故障時拒絕或放行的政策。 — 完成條件：每個入口清楚標示；敏感 API 預設拒絕；公開站可經批准採降級放行並告警。
- [ ] **WAF-007** 管理員可以查看防護健康狀態與延遲。 — 完成條件：Agent 停止、規則載入失敗或逾時立即標示降級，不仍顯示綠色保護中。
- [ ] **WAF-008** 使用者可以檢查正常請求是否被誤擋。 — 完成條件：提供遮罩證據、規則 ID 與請求關聯碼；事件內容不能在管理介面執行腳本。
- [ ] **WAF-009** 管理員可以逐步發布政策到多節點。 — 完成條件：顯示每個節點已套用版本；局部失敗不宣稱全域生效。
- [ ] **WAF-010** 管理員可以查看封鎖與例外到期時間。 — 完成條件：臨時例外到期後自動依政策失效；相互衝突的 allow／deny 有固定優先規則。
- [ ] **WAF-011** 管理員可以匯出安全事件與稽核摘要。 — 完成條件：不包含完整 Token、Cookie、密碼或預設保存的完整請求 body。
- [ ] **WAF-012** 平台可以拒絕有歧義的 HTTP 請求。 — 完成條件：重複衝突 Host、長度與轉送資訊有一致解析策略，代理與 WAF 不各看不同內容。
- [ ] Agent 停止或規則載入失敗時立即標示降級，不顯示綠色保護中

## Acceptance tests（第 42 章）

- **T-086** WAF 只有設定，但外部 Agent 沒啟動。 → 不顯示防護正常，依政策處理請求與告警。
- **T-087** WAF 偵測模式收到測試攻擊。 → 有偵測事件但不當作已攔截。
- **T-088** WAF 阻擋模式收到有效攻擊與合法請求。 → 攻擊被阻擋，合法請求通過；證據含規則與版本。
- **T-089** WAF 逾時或崩潰。 → 按每站點公開的失效策略，沒有悄悄改成放行。
- **T-090** 大型壓縮 body、超大上傳及分段請求。 → 大小與解壓預算生效；超過檢查範圍明示，不假稱全量掃描。
