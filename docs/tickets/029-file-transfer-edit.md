## What it delivers

分段上傳 API（目標、大小上限、校驗、有效期）、續傳、文字編輯（編碼、換行、並行衝突）、壓縮解壓縮防穿越、隔離預覽。

## Acceptance criteria

- [ ] **FIL-003** 使用者可以上傳、下載與傳輸大檔案或資料夾。 — 完成條件：支援分段／續傳、總量限制、進度及完整性檢查；中斷不留下被誤認為完成的檔案。
- [ ] **FIL-004** 使用者可以線上編輯文字檔。 — 完成條件：編碼、換行及權限不被無意改變；有大小限制、變更比較與並行編輯衝突。
- [ ] **FIL-006** 使用者可以壓縮與解壓縮授權檔案。 — 完成條件：拒絕路徑穿越、惡意符號連結與超出配額的解壓縮；原檔不被靜默覆寫。
- [ ] **FIL-012** 使用者可以預覽安全檔案類型。 — 完成條件：HTML、SVG 等可執行內容不得在管理面板同來源直接執行，避免偷取登入狀態。
- [ ] 中斷不留下被誤認為完成的檔案
- [ ] HTML／SVG 不在管理面板同來源直接執行
- [ ] 檔案頁可直接開啟編輯器（對齊 1Panel）：分頁、行號、語法上色、搜尋取代、自動換行、語言／編碼／換行格式、版本歷史與比較、全螢幕；狀態列顯示游標、編碼、換行、大小、未儲存與外部修改。
- [ ] 有讀取權的使用者看到檔案原文，`.env` 等機密檔不遮罩；開啟與儲存機密類檔案記入稽核。
- [ ] 未儲存時關閉分頁、離開頁面或關閉瀏覽器，先詢問「儲存／不儲存／取消」；點背景不關閉編輯器對話框。

## Acceptance tests（第 42 章）

- **T-040** 解壓縮含 `../` 與外指符號連結的壓縮檔。 → 不寫出授權目錄，列出拒絕項目。
- **T-041** 檔案預覽內容含執行腳本。 → 在隔離預覽或文字呈現，不在管理來源執行。
- **T-042** 大檔上傳中斷後續傳。 → 檢查分段與整檔，完成前不當正式檔使用。
