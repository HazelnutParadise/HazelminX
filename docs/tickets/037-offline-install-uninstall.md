**Status:** blocked

**Issue:** [#37](https://github.com/HazelnutParadise/hazelminx/issues/37)  

## What it delivers

離線包完整性清單、安裝時偵測 1Panel／Portainer 的雙重管理風險、按需安裝額外能力的預覽、卸載選項（平台／平台資料／選配元件）、維護缺口移交、只清除可證明屬於自己的變更、本機報告。

## Acceptance criteria

- [ ] **INS-011** 管理員可以使用離線安裝包。 — 完成條件：包含選定功能需要的執行檔、映像、規則、授權及完整性清單；缺少檔案在變更前指出。
- [ ] **INS-012** 管理員可以解除安裝平台，選擇是否保留管理資料。 — 完成條件：預設保留應用與持久資料；不移除原本就存在的 Docker、資料庫或共用套件。
- [ ] **INS-014** 安裝程式可以識別已有 1Panel、Portainer 或其他控制工具。 — 完成條件：告知相同資源的雙重管理風險；沒有移交批准不停止它們或修改其資料。
- [ ] **PKG-003** 管理員可以按需安裝額外能力。 — 完成條件：安裝前顯示新增套件／服務／版本／來源；取消不造成變更。
- [ ] **UN-001** 管理員可以移除平台但留下應用。 — 完成條件：原有容器、資料庫、模型、掛載與持久資料不被刪除或重建。
- [ ] **UN-002** 管理員可以選擇是否清除平台資料。 — 完成條件：刪除清單先呈現；保留資料有位置與用途說明；不把保留狀態稱為完全清空。
- [ ] **UN-003** 管理員可以知道卸載造成的維護缺口。 — 完成條件：Zentinel、Token 驗證、WAF、憑證續期、備份與磁碟保護的影響都列出並處理。
- [ ] **UN-004** 卸載器可以只清除可證明屬於自己的變更。 — 完成條件：不移除共用套件、不恢復過時防火牆規則、不沿符號連結誤刪其他路徑。
- [ ] **UN-005** 管理員可以在 UI 消失後取得結果。 — 完成條件：本機報告或 CLI 仍可查卸載結果；需要重開機或人工處理時明確列出。
- [ ] 不移除原本就存在的 Docker、資料庫或共用套件
- [ ] 符號連結與重新解析點不把刪除導向別處

## Acceptance tests（第 42 章）

- **T-002** 安裝到已有 1Panel 與正式容器的主機。 → 偵測衝突並提出計畫；未批准前不改舊服務。
- **T-010** 使用完整離線包安裝。 → 不默默連外抓缺少元件；缺件時列清單。
- **T-011** 解除安裝 HazelminX，選保留應用。 → 應用與資料不刪；已移除與保留項目可核對。
- **DEP-T09** 普通卸載平台，主機原本就有 Docker 和資料庫。 → 原有套件、資料、容器及帳號權限未被誤移除。
- **DEP-T10** 欲移除正在為網站服務的 Zentinel／WAF。 → 先列網站與授權影響；未批准不停止入口、不降低保護。
- **DEP-T11** 應用開機依賴 Agent 的資料磁碟檢查。 → 卸載前完成保護移交或明確停用依賴的自動啟動，不留下不安全配置。
- **DEP-T12** 檔案目錄內放符號連結或 Windows 重新解析點。 → 卸載不越界刪除；被使用者修改的設定先比對再處理。
