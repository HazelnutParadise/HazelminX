## What it delivers

跨節點資源視圖（同名不混）、批次操作逐台結果、遠端節點出站代理與自訂 CA。

## Acceptance criteria

- [ ] **NOD-010** 管理員可以在單一畫面查看跨節點資源。 — 完成條件：相同名稱但不同節點的服務不混在一起；批次操作逐台顯示結果。
- [ ] **NOD-012** 管理員可以為遠端節點設定出站代理與自訂 CA。 — 完成條件：TLS 驗證仍有效；代理密碼遮罩；不要求以「略過驗證」才可使用。
- [ ] **UI-009** 使用者可以批次操作多個資源，逐一知道成功與失敗。 — 完成條件：一項失敗不掩蓋其他結果；批次刪除列明全部目標與資料保留方式。
