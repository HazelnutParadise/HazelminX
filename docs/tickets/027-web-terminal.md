## What it delivers

pty 終端機串流（期限、大小變更、斷線清理、來源紀錄、貼上敏感內容警告）、明確顯示 Linux 身分、稽核政策（中繼資料預設、完整錄製另啟）。

## Acceptance criteria

- [ ] **SSH-006** 使用者可以在網頁使用授權終端機。 — 完成條件：連線有期限、大小變更、斷線清理與來源紀錄；貼上敏感內容前可警告。
- [ ] **SSH-007** 管理員可以設定終端機稽核政策。 — 完成條件：預設記錄連線與操作中繼資料；完整錄製需另行啟用並處理密碼與個資風險。
- [ ] **IAM-007** 具權限者可以使用受控終端機，並明確知道它代表的 Linux 身分。 — 完成條件：無終端機權限者不能透過檔案、排程或容器功能繞過限制。
- [ ] 無終端機權限者不能透過檔案、排程或容器功能繞過
- [ ] 使用者停權時依政策停止已開啟的工作階段
- [ ] （增補 03 ROB-005，擁有票 017）終端機分頁顯示目標的用途等級徽章；正式等級以紅框標示。
