## What it delivers

每種語言的建立／版本／設定／狀態／日誌／移除、來源與工作目錄與啟動方式預覽、擴充與依賴、環境變數與健康檢查共用資料來源、共用或獨立環境、資料庫與檔案帳號連結、PHP 相容層（WordPress／Laravel／PHP-FPM 流程測試）。

## Acceptance criteria

- [ ] **RUN-001** 使用者可以建立及管理基線支援的各語言執行環境。 — 完成條件：每種語言都有建立、版本、設定、狀態、日誌及移除流程，不只提供選單。
- [ ] **RUN-002** 使用者可以設定來源目錄、工作目錄、建置與啟動方式。 — 完成條件：預覽實際命令、身分與權限；不把任何專案設定自動當 root 腳本。
- [ ] **RUN-003** 使用者可以管理語言版本、依賴與擴充。 — 完成條件：PHP 擴充及設定、套件安裝與鎖定版本可查；不偷偷使用全主機共用環境污染其他網站。
- [ ] **RUN-004** 使用者可以設定環境變數、服務 Port、資源與健康檢查。 — 完成條件：與專案設定、機密及網站路由同一資料來源，不另外存互相矛盾的版本。
- [ ] **RUN-005** 使用者可以重新建置、啟停與更新執行環境。 — 完成條件：顯示受影響網站；失敗保留可用版本；符合條件才宣稱不中斷。
- [ ] **RUN-006** 管理員可以設定共用或網站獨立的執行環境。 — 完成條件：共用模式顯示所有相依網站；權限與資料隔離符合選定政策。
- [ ] **RUN-007** 使用者可以在建站時連結資料庫與檔案帳號。 — 完成條件：分別建立最小範圍帳號；建立中途失敗不刪除原有共用資源。
- [ ] **RUN-008** 維護者可以驗證原網站行為與新環境相同。 — 完成條件：版本、編碼、上傳、背景工作、靜態檔、時區及主要業務流程逐項測試。
- [ ] 兩站共用環境時移除其中一站不刪另一站與共用資料
