## What it delivers

change-plans API 與畫面：影響範圍、預檢結果、風險、必要批准、有效期限；批准綁定摘要與資源版本；設定差異與受影響服務預覽；版本衝突畫面。

## Acceptance criteria

- [ ] **IAM-005** 管理員可以批准特定高風險變更計畫。 — 完成條件：批准綁定內容摘要、目標、版本與期限；內容改變必須重新批准。
- [ ] **ENG-005** 管理員可以批准一份明確變更計畫。 — 完成條件：批准綁定計畫摘要、資源版本及期限；內容變更後原批准失效。
- [ ] **UI-006** 使用者修改設定前可看差異與受影響服務。 — 完成條件：高風險操作顯示實際節點／磁碟／環境名稱，不能只有「確定嗎」。
- [ ] 兩人同時修改同一設定版本時第二人看到差異與衝突，不覆蓋第一人

## Acceptance tests（第 42 章）

- **T-030** 兩人同時修改同一設定版本。 → 第二次收到差異與衝突，不覆蓋第一人。
