## What it delivers

平台設定頁全部分頁：名稱／語言／時區／外部位址／預設節點、監聽位址與 HTTPS（含復原方法）、允許來源與入口路徑、平台 API／出站代理／信任 CA、通知帳號與測試、更新通道、快照與匯出、遙測開關、版本與相容資訊。

## Acceptance criteria

- [ ] **SET-001** 管理員可以設定面板名稱、語言、時區、外部位址與預設節點。 — 完成條件：設定有作用範圍；不把節點時區與使用者顯示時區混為一談。
- [ ] **SET-002** 管理員可以修改管理監聽位址、Port、網域與 HTTPS。 — 完成條件：檢查衝突與可達性；在新入口可用前保留復原方法。
- [ ] **SET-003** 管理員可以設定允許來源與選用的管理入口路徑。 — 完成條件：保留基線能力；特殊路徑不是唯一驗證方式；變更不永久鎖住本人。[S37](#source-S37)
- [ ] **SET-005** 管理員可以管理平台 API、出站代理與信任 CA。 — 完成條件：範圍及秘密受控；不能以跳過 TLS 驗證當正常設定。
- [ ] **SET-006** 管理員可以設定通知帳號、告警路由與測試訊息。 — 完成條件：顯示送達或供應商接受的證據，兩者不混稱；測試不包含正式秘密。
- [ ] **SET-007** 管理員可以選穩定／測試更新通道與檢查頻率。 — 完成條件：預設穩定版；不自動切上游 1Panel 更新器；每次更新有來源與相容資訊。
- [ ] **SET-008** 管理員可以管理平台快照、設定匯入匯出與診斷包。 — 完成條件：使用相同備份與機密政策，匯出前可預覽內容，不自動送外部。
- [ ] **SET-009** 管理員可以選擇是否傳送使用資訊給外部。 — 完成條件：預設關閉非必要遙測；更新與商店連線有明確用途與目的地。
- [ ] **SET-010** 使用者可以查看版本、元件相容、授權與已知限制。 — 完成條件：不把候選或未驗證能力顯示成可用；法律資訊保留來源。
- [ ] 變更入口後失聯時可用已確認救援路徑復原
- [ ] 停用遙測後只剩已授權更新、商店或整合流量

## Acceptance tests（第 42 章）

- **T-132** 變更管理入口 Port、來源限制與 HTTPS 後失聯。 → 可用已確認救援路徑復原，不依賴同一條壞掉入口。
- **T-133** 停用外部遙測，觀察平台出站。 → 只剩已授權更新、商店或整合流量，沒有隱藏使用資料上傳。
