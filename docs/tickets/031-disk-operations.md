**Epic:** 磁碟與儲存（`epic:storage`）  
**User Story:** 維運者可以管理儲存  
**Milestone:** M1 單機主機管理  
**Blocked by:** [012 維運者可以執行需要高權限的固定動作，而 Agent 主程序維持低權限](012-privileged-executor.md), [016 管理員可以預覽並批准高風險變更計畫，內容改變時原批准失效](016-change-plans.md), [030 維運者可以查看磁碟、分割區、檔案系統、健康與容量告警](030-disk-overview-alerts.md)  
**Status:** blocked  
**規格章節:** 13｜磁碟、儲存與資料位置、08｜安裝、更新、開機自啟與解除安裝  
**Issue:** [#31](https://github.com/HazelnutParadise/hazelminx/issues/31)  

## What it delivers

破壞性操作走變更計畫；裝置 ID 與用途重新核對；系統碟與使用中資源保護；依檔案系統能力顯示操作；SMB／NFS 掛載憑證不進命令列；缺工具時說明並允許安裝。

## Acceptance criteria

- [ ] **STO-002** 維運者可以建立分割區、格式化、掛載與設定開機掛載。 — 完成條件：重新核對裝置 ID、容量與用途；系統碟與正在使用的資源受到保護。
- [ ] **STO-003** 維運者可以管理 ext4、XFS、Btrfs、LVM、軟體 RAID 與 LUKS。 — 完成條件：依工具與檔案系統能力顯示操作；不可縮小者不能提供會破壞資料的縮小按鈕。
- [ ] **STO-004** 維運者可以掛載 SMB／NFS 網路儲存。 — 完成條件：憑證不寫入可讀命令列；失聯與逾時不凍結整個管理介面。
- [ ] 兩個路徑指向同一磁碟時鎖與使用檢查認出同一資源
- [ ] NFS／SMB 斷線時不切換成同名本機空目錄

## Acceptance tests（第 42 章）

- **T-044** 兩個路徑其實指向同一顆磁碟，同時操作。 → 鎖與使用檢查認出同一資源。
- **T-045** 格式化系統正在使用的磁碟。 → 前置檢查阻擋，列出相依服務。
- **T-049** 檔案系統沒有支援要求的調整操作。 → 明確拒絕，不套用其他檔案系統命令猜測。
- **T-050** NFS／SMB 暫時斷線。 → 顯示掛載異常；不切換成同名本機空目錄。
- **DEP-T03** 主機沒有額外磁碟工具。 → 基本管理仍能使用，進階磁碟頁明確指出工具需求。
