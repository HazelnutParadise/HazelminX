## What it delivers

通用框架：模組＝systemd 服務＋設定檔對映＋驗證指令＋重載指令＋狀態來源；結構化／原始編輯切換、套用前驗證、版本與回滾、具名動作、adapter 範本。

## Acceptance criteria

- [ ] **HSM-001** 維運者可以在「服務模組」頁看到每個節點上各模組的安裝、執行、版本與設定檔是否通過驗證。 — 完成條件：未安裝與已安裝未啟用分開顯示；驗證失敗列出指令原始輸出。
- [ ] **HSM-002** 維運者可以用結構化表單或原始檔編輯模組設定，套用前先跑該模組的驗證指令。 — 完成條件：驗證失敗不寫入；不認識的合法指令原樣保留；每次套用留版本可回滾。
- [ ] **HSM-003** 維運者可以安裝、啟用、停用、移除模組對應的套件與服務。 — 完成條件：走套件管理（SYS-002）與 systemd（SYS-004）；移除前列出仍引用的設定與資料。
- [ ] **HSM-013** 每個模組的操作都走工作引擎與高權限執行器，具名動作，不開任意 shell。 — 完成條件：參數安全（SEC-006）測試涵蓋每個模組的路徑與名稱欄位。
- [ ] **HSM-014** 模組可由維護者以 adapter 新增（INT-007）。 — 完成條件：新模組只需提供對映、驗證、重載、狀態四件事；文件列出範本。
