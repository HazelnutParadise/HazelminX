## What it delivers

目的地 adapter、基線供應商逐項對應、分項測試（登入／上傳／讀回／刪除）、憑證與 OAuth 輪替、節點與任務限制、傳輸加密與自訂 CA、容量未知顯示、停用與移除、離線節點預授權。

## Acceptance criteria

- [ ] **BAK-001** 管理員可以建立多個本機、S3 相容、SFTP、WebDAV、Google Drive、OneDrive 與掛載 NAS 目的地。 — 完成條件：每個目的地有名稱、範圍、路徑、能力、驗證方式與權限，不要求使用平台預設磁碟。
- [ ] **BAK-002** 管理員可以保留基線既有備份供應商。 — 完成條件：逐項實作對應 adapter；不因列表未寫到某家就刪除舊能力。
- [ ] **BAK-003** 管理員可以測試連線與實際讀寫。 — 完成條件：分開測試登入、上傳、讀回與允許的刪除；唯寫／不可變目的地不因禁止刪除而誤判全部失敗。
- [ ] **BAK-004** 管理員可以輪替密碼、金鑰與 OAuth 授權。 — 完成條件：執行中工作使用已固定的憑證版本；新版本失效可診斷，權限不擴大。
- [ ] **BAK-005** 管理員可以限制哪些節點與任務使用某個帳號。 — 完成條件：一般使用者不能匯出帳號明文；節點只取得該工作必要的憑證。
- [ ] **BAK-006** 管理員可以設定傳輸加密、代理、自訂 CA 與頻寬上限。 — 完成條件：來源伺服器驗證正確；不預設跳過 TLS／SSH 指紋檢查。
- [ ] **BAK-007** 管理員可以查看容量、配額、成本相關限制及最近測試。 — 完成條件：供應商無法提供容量時顯示未知；不虛構剩餘空間。
- [ ] **BAK-008** 管理員可以停用或移除備份帳號。 — 完成條件：顯示依賴任務與既有備份；刪除設定不等於刪除遠端檔案。
- [ ] **BAK-009** 管理員可以使用離線／異地備份目的地。 — 完成條件：中央暫時離線時，經事先授權的節點備份可依策略執行；結果稍後補報。
