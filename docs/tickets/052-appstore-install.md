## What it delivers

1Panel 官方商店同步（分類、版本、參數、相依）、安裝預覽（實際 Compose、路徑、腳本）、相依資料庫共用或獨立、腳本與權限可見、引擎／架構相容標示、漏洞與授權資訊時間。

## Acceptance criteria

- [ ] **APP-001** 管理員可以同步、搜尋與使用 1Panel 官方商店。 — 完成條件：保留分類、版本、說明、必要參數及相依服務；不能要求另外維護重複清單才可用。
- [ ] **APP-003** 管理員可以安裝整套應用，選擇節點、網路、Port 與資料位置。 — 完成條件：預覽實際 Compose、路徑及需執行腳本；預檢失敗不留下半套正式服務。
- [ ] **APP-004** 管理員可以重用或新增相依資料庫、Redis 等服務。 — 完成條件：明示共用或獨立；卸載一個應用不刪除其他應用使用的共用資料庫。
- [ ] **APP-009** 管理員可以查看安裝與更新腳本。 — 完成條件：腳本來源、權限、檔案與網路需求可見；高權限行為需對應批准，不以商店可信為由省略。
- [ ] **APP-011** 管理員可以知道每個應用支援哪些引擎與架構。 — 完成條件：Docker、Podman、Kubernetes、x86_64、ARM64 逐組標示；沒有測試不顯示完全相容。
- [ ] **APP-012** 管理員可以在安裝前檢查版本、漏洞與授權資訊。 — 完成條件：明示資料時間及來源；掃描不到不代表沒有漏洞；不自動執行付費掃描。
- [ ] 預檢失敗不留下半套正式服務
- [ ] 初始化腳本拿到使用者真正選定的路徑
